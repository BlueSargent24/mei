
### Crystal habits
- general appearance or growth style of a crystal
@perkinsMineralogy2014

| Individual crystal habit | Colloquial description     | Crystal dimensions     |
| ------------------------ | -------------------------- | ---------------------- |
| Equant                   | equal dimensions           | a=b=c                  |
| Tabular                  | tablet or diskette-like    | a=b>c; c is thin       |
| Platy                    | sheet-like                 | a=b>>c; c is very thin |
| Prismatic or columnar    | pillar-like or column-like | a>b=c; a is long       |
| Bladed                   | blade- or knife-like       | a>b>c                  |
| Acicular                 | needle-like                | a>>>b=c                |
| capillary or filiform    | hair-like                  | a>>>b=c                |

| Crystal aggregates         |                                                                                                                  |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| **Geodes**                 | partial/complete filling of a subspherical cavity as crystallization proceed from the walls of the cavity inward |
| **Concretion**             | grow outward from central nucleus within a rock body                                                             |
| **Fibrous**                | parallel arrangement of acicular or filiform crystals                                                            |
| **Radiating**              | acicular-filiform crystals radiating outward from a central point                                                |
| **Divergent**              | prismatic crystals diverging from a common area                                                                  |
| **Reticulated**            | lattice-work of tabular to bladed crystals                                                                       |
| **Roseiform**              | petal-like arrangement of tabular or bladed crystals                                                             |
| **Drusy**                  | surface, lined with very small, goosebump-like crystals                                                          |
| **Dendritic, arborescent** | tree-like, branching network of crystals                                                                         |
| **Lamellar/foliated**      | sub-parallel layers of minerals                                                                                  |
| **Massive**                | aggregate of very small crystals with a fine-grained appearance                                                  |
| **Granular**               | subequant, macroscopic crystal aggregates with a granular appearance                                             |
| **Banded**                 | parallel layers of small mineral with different color; agate                                                     |
| **Concentric**             | spherical to sub-spherical layers about a common center                                                          |
| **Botryoidal/colloform**   | rounded, mound-like aggregates; kidney-like                                                                      |
| **Oolitic**                | spherical, concentrically layered, sand-sized (<2mm) grain aggregates                                            |
| **Pisolitic**              | spherical, concentrically layered, gravel-sized aggregates                                                       |
| **Amygdaloidal**           | spherical to ellipsoidal gas vesicles infilled with secondary minerals                                           |
