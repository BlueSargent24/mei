## Hexagonal
### Normal / [[beryl]] Type
- Dihexagonal Bipyramidal or Holohedral
### Hemimorphic / Zincite Type
### Tripyramidal / Apatite Type
### Pyramidal-Hemimorphic / Nephelite Type
- Hexagonal Pyramidal or Pyramidal Hemihedral Hemimorphic
### Trapezohedral Class
- Hexagonal Trapezohedral or Trapezohedral Hemihedral
# Hexagonal Minerals
