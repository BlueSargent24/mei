# Nitrogen

## General

* Atomic no.: 7
* Atomic mass: 14.006
* Electron configuration: 1s² 2s² 2p³
* Oxidation states: -3, +3, +5
* Condensation point: -196°C
* ~78% of atmosphere as N₂
* Essential in proteins and nucleic acids
* Crustal abundance: ~0.3 ppm
* Strong triple bond → relatively inert

---

## Nitrogen Cycle

* Fixation: N₂ → NH₃/NH₄⁺
* Ammonification: organic N → NH₃/NH₄⁺
* Nitrification: NH₄⁺ → NO₂⁻ → NO₃⁻ (oxidation)
* Denitrification: NO₃⁻ → N₂ (anoxic)

### Reservoirs

| Reservoir  | Form               |
| ---------- | ------------------ |
| Atmosphere | N₂                 |
| Biosphere  | Organic N          |
| Soil       | NH₄⁺, NO₃⁻         |
| Oceans     | Dissolved nitrate  |
| Sediments  | Organic N          |
| Mantle     | NH₄-bearing phases |
