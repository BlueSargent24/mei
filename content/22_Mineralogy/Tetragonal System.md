# Description
- 7 classes

## Classes

### Normal / Zircon Type
- Ditetragonal Bipyramidal or Holohedral

| Forms                       |     |
| --------------------------- | --- |
| **Base or basal pinacoid**      |     |
| **Prism of the first order**    |     |
| **Prism of the second order**   |     |
| **Ditetragonal prism**          |     |
| **Pyramid of the first order**  |     |
| **Pyramid of the second order** |     |
| **Ditetragonal pyramid**        |     |
### Hemimorphic / Iodosuccinimide Type
- Ditetragonal Pyramidal or Holohedral Hemimorphic
- differs from the normal class only in having no horizontal plane of symmetry
### Tripyramidal / Scheelite Type
- Tetragonal Bipyramidal or Pyramidal Hemihedral
- one plane of symmetry only, that of the horizontal crystallographic axes and one axis of tetragonal symmetry normal to it
- **Prism and pyramid of the third order**

### Pyramidal-Hemimorphic / Wulfenite Type
- Tetragonal Pyramidal or Hemihedral Hemimorphic

### Sphenoidal / Chalcopyrite Type
- Tetragonal Sphenoidal, Sphenoidal Hemihedral or Scalenohedral Class
- forms: **sphenoid** and **tetragonal scalenohedron**

### Trapezohedral / Nickel Sulphate Type
- Tetragonal Trapezohedral or Trapezohedral Hemihedral
- analogous to the plagiohedral class
- absence of any plane/center of symmetry

### Tetartohedral
- Tetragonal Bisphenoidal or Sphenoidal Tetartohedral
