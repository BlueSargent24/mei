## Trigonal or Rhombohedral
### Trigonal / Benitoite Type
- Ditrigonal Bipyramidal, Trigonal Hemihedral or Trigonotype
### Rhombohedral / Calcite Type
- Ditrigonal Scalenohedral or Rhombohedral Hemihedral
### Rhombohedral-Hemimorphic / Tourmaline Type
- Ditrigonal Pyramidal or Trigonal Hemihedral Hemimorphic
### Trapezohedral / Quartz Type

# Trigonal Minerals
```dataview
TABLE WITHOUT ID
file.link AS "Mineral", crystalclass AS "Class"
WHERE crystalsystem = "Trigonal"
```
